# Citing torch-dgx

If you use torch-dgx in a publication, please cite the following paper. Include
the software version used when reproducibility depends on a specific release.

## Preferred citation

Matthew Cong, Francis Williams, Jonathan Swartz, Mark Harris, Sanja Fidler, and
Ken Museth. *A Scalable PyTorch Abstraction for Multi-GPU Gaussian Splatting*.
arXiv:2606.11390, 2026. [Paper](https://arxiv.org/abs/2606.11390).
