# Supported Layers and Operators

## Supported Layers

Supported `torch.nn` modules include:

- `Linear`
- `Conv2d`
- `AvgPool2d`
- `Embedding`
- `Dropout`
- `Unfold`
- `ReflectionPad2d`
- `ReLU`
- `GELU`
- `Sigmoid`
- `SiLU`
- `Softmax`
- `LogSoftmax`
- `Tanh`
- `Threshold`
- `GroupNorm`
- `LayerNorm`
- `RMSNorm` (FP32 and FP64, forward and backward)
- `L1Loss`
- `MSELoss`
- `NLLLoss`
- `CrossEntropyLoss` with class-index targets and `label_smoothing=0`
- `UpsamplingNearest2d`

## Supported Operators

The ATen overloads below also serve public PyTorch APIs through composite
operations. Dtype and layout support varies by operator.

- **SDPA:** FP32 CUTLASS forward/backward on Ampere or newer GPUs, with masks,
  causal attention, and dropout. Fused execution requires matching batch/head
  counts and channel dimensions divisible by four and at most 65,536.
- **Convolution:** ungrouped, non-transposed 2D; FP16/BF16/FP32/FP64 forward,
  FP32/FP64 backward. Average pooling supports all four dtypes in both directions.
- **Limits:** native top-k requires CCCL 3.2+; linear solves support FP32/FP64
  2x2 systems. Fused Adam/AdamW require aligned, contiguous FP32/FP64 tensors,
  without AMSGrad, maximize, or AMP gradient scaling; Adam requires zero weight decay.
